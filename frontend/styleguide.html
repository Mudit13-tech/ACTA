Design system

The tools everything else is built from.

One token file drives colour, type, space, radius, elevation and motion. Components pick a glass level and a token — never a raw hex value — so a theme change is a variable change, not a rewrite.

Colour

Brand ramp, semantic state and themed surfaces. Light theme redefines only the themed layer.

Typography

Space Grotesk for display, Inter for text, JetBrains Mono for machine output. The scale is fluid.

Glass elevations

Three levels, plus a specular rim and optional tint. Blur drops automatically on low-end devices.

Space & radius

A 4pt scale and six radii. Touch targets never go below 44px.

Components

Every control in the product, in one place.

Icons

A single stroked 24px set, inlined as SVG so they inherit colour and weight.

Motion

Expo-out is the house curve. Tap the easings to compare them; everything stops under reduced motion.
