The action loop

Eight stages, one engine.

The platform is built around an agentic action loop rather than a single domain workflow. Every vertical reuses the same stages — new domains arrive as connectors, not rewrites.

    System architecture

    Autonomy & safety

    The agent never infers permission from intent.

    Before any sensitive action, an explicit policy is evaluated. Spend limit, category, action type, vendor, timing, data access and confidence each get a vote — and any one of them can stop the run.

    Failure path: FAILED → RETRY / ESCALATE / ROLLBACK
